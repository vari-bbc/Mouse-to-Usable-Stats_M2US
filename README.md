# M2US

This program takes either the output from the QUINT workflow or a specific file format and allows you to create two types of heatmaps as well as run a per region statistical analysis of your data. One heatmap is a normal rectangular heatmap while the other is an anatomical heatmap which displays data on top of a mouse brain outline (outline from the Allen Brain Atlas). The statistical analysis compares a variable of interest (eg treatment) within each region and strata using a non-parametric ranked ANOVA, automatically adjusting for sex and batch when those are present, and calling significance by either second generation p-values or an FDR cutoff. The results can be viewed as a statistical anatomical heatmap showing the estimated difference, adjusted p-value, significance, or mean difference, or as a per region boxplot. There are a couple output files throughout the app to save your spot for easy return as well as easy download of the heatmaps, boxplots, statistics tables, and data behind them. The app is hosted at: https://vai-bbc.shinyapps.io/Stats_Mouse_To_Usable_M2U/.
